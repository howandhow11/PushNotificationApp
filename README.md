# PushNotificationApp 🚀

A React Native Firebase app with Authentication, Push Notifications, Scheduled Notifications, and Firestore integration.

---

## ✨ Features

* Firebase Authentication
* Push Notifications
* Local Notifications
* Scheduled Notifications
* Firestore Database
* Login & Signup Screens
* Modern UI
* Android Support

---

## 📱 Screens

* Splash Screen
* Login Screen
* Signup Screen
* Home Screen
* Notification Screen

---

## 🛠 Tech Stack

* React Native
* Firebase
* Firestore
* Firebase Messaging (FCM)
* Notifee
* React Navigation
